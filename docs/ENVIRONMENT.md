# Environment configuration

Production and staging fail fast unless PostgreSQL, HTTPS application/frontend/
webhook/Mini App URLs, exact CORS origins, a bot token, webhook secret, and a
32+ character session signing secret are configured. `TEST_DATABASE_URL` is
mandatory only with `APP_ENV=test` and must differ from `DATABASE_URL`.

Core and identity:

- `APP_ENV`, `APP_BASE_URL`, `FRONTEND_BASE_URL`, `PUBLIC_V2_ENABLED`
- `DATABASE_URL`, `TEST_DATABASE_URL`
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`,
  `TELEGRAM_WEBHOOK_URL`, `TELEGRAM_MINI_APP_URL`
- `TELEGRAM_AUTH_MAX_AGE_SECONDS`, `MAX_WEBHOOK_BODY_BYTES`
- `SESSION_SIGNING_SECRET`, `SESSION_MAX_AGE_SECONDS`,
  `SESSION_COOKIE_NAME`, `CSRF_COOKIE_NAME`, `CORS_ORIGINS`
- `INVITE_ONLY`; `TELEGRAM_ADMIN_ID` is legacy-only and grants no public-v2
  access.

AI, nutrition, and voice:

- `AI_AGENT_ENABLED`, `AI_PROVIDER`, `AI_AGENT_MIN_CONFIDENCE`,
  `AGENT_PENDING_TTL_MINUTES`, `MAX_AGENT_INPUT_LENGTH`
- `GROQ_API_KEY`, `GROQ_MODEL`, `LLM_TEMPERATURE`
- `NUTRITION_PROVIDER`, `WHISPER_MODEL`, `WHISPER_LANGUAGE`
- `MAX_VOICE_FILE_SIZE`, `MAX_VOICE_DURATION_SECONDS`,
  `VOICE_DOWNLOAD_TIMEOUT_SECONDS`, `TRANSCRIPTION_TIMEOUT_SECONDS`,
  `VOICE_PROVIDER_MAX_ATTEMPTS`

Abuse and privacy:

- `MAX_TEXT_ENTRY_LENGTH`, `PER_USER_REQUESTS_PER_MINUTE`,
  `PER_USER_DAILY_TEXT_LIMIT`, `PER_USER_DAILY_AI_LIMIT`,
  `PER_USER_DAILY_NUTRITION_LIMIT`, `PER_USER_DAILY_SUMMARY_LIMIT`,
  `PER_USER_DAILY_EXPORT_LIMIT`, `PER_USER_DAILY_VOICE_MINUTES`,
  `MAX_REMINDERS_PER_USER`
- `MESSAGE_CLEANUP_ENABLED`, `MESSAGE_CLEANUP_DELAY_SECONDS`,
  `ACCOUNT_DELETION_RECENT_AUTH_SECONDS`,
  `OPERATIONAL_METADATA_RETENTION_DAYS`,
  `OPERATIONAL_PRUNE_INTERVAL_SECONDS`

Worker and monitoring:

- `REMINDER_WORKER_ENABLED`, `WORKER_POLL_INTERVAL_SECONDS`,
  `WORKER_BATCH_SIZE`, `WORKER_LEASE_SECONDS`, `WORKER_MAX_ATTEMPTS`,
  `WORKER_BASE_BACKOFF_SECONDS`, `WORKER_HEARTBEAT_INTERVAL_SECONDS`,
  `WORKER_HEARTBEAT_STALE_SECONDS`
- `INTERNAL_MONITORING_TOKEN`, `SENTRY_DSN`, `LOG_LEVEL`, `LOG_FILE`,
  `JSON_LOGS`, `DEBUG`, `DISABLE_SSL_VERIFY`

Legacy-only development variables are `WEBHOOK_URL`, `CHROMA_PERSIST_DIR`,
`AUDIO_TEMP_DIR`, `TIMEZONE`, `DAILY_REFLECTION_HOUR`,
`DAILY_REFLECTION_MINUTE`, `WEEKLY_SUMMARY_DAY`, `WEEKLY_SUMMARY_HOUR`,
`WEEKLY_SUMMARY_MINUTE`, `MORNING_NUDGE_HOUR`,
`MORNING_NUDGE_MINUTE`, and `NUDGE_THRESHOLD_HOURS`. They do not enable a
public capability. `DISABLE_SSL_VERIFY=true` is forbidden outside development.

`.env.example` contains placeholders and safe disabled defaults only. Platform
secret stores must supply real values; never copy a staging secret into
production.
